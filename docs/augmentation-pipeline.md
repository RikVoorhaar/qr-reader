Synthetic QR compositing pipeline

Goal: generate deterministic test images where a QR code appears as a realistic sticker / laminated label on an indoor background.

Inputs:

background image
payload string
QR version
error correction level
random seed
augmentation config

Outputs:

composited image
payload
version
N = 4 * version + 17
QR image-space corners: TL, TR, BR, BL
homography: QR grid -> image
augmentation metadata
1. Select background
rng = Random(global_seed, sample_index)

background = deterministic choice from background manifest
background = resize/crop to target resolution

Suggested target resolutions:

640x480
1280x720
1920x1080

Keep background selection deterministic:

background_index = rng.randint(0, num_backgrounds - 1)
2. Generate QR matrix

Generate a standard QR matrix from:

payload
version
error correction level
mask mode, optional fixed/random

Let:

N = 4 * version + 17
quiet_zone = 4 modules

Render binary QR patch with quiet zone:

patch_modules = N + 2 * quiet_zone

Use a configurable pixels-per-module:

ppm = sampled from range, e.g. 3..20
patch_size_px = patch_modules * ppm

Render with imperfect colors:

white_color ≈ [220..255, 220..255, 220..255]
black_color ≈ [0..40, 0..40, 0..40]

Do not blur the QR modules yet. Keep internal module edges sharp at this stage.

3. Add physical patch appearance

Treat the QR as printed on a rectangular sticker/label.

Optional but useful:

paper_tint:
  multiply RGB by mild color vector
  e.g. [0.95..1.05, 0.95..1.05, 0.95..1.05]

contrast_scale:
  reduce contrast mildly
  e.g. 0.85..1.00

brightness_shift:
  e.g. -10..+10

Optional laminated effect:

add weak smooth highlight:
  create large blurred ellipse or linear gradient
  strength e.g. 0..25 intensity values
  apply mostly to white/quiet-zone areas, or to whole patch

Keep this mild. It should not destroy module contrast.

4. Choose placement and perspective transform

Sample target QR size in the output image. Useful parameter:

pixels_per_module_in_image

Typical ranges:

easy:   8..16 px/module
medium: 4..10 px/module
hard:   2..6 px/module

Choose a center location where the projected quadrilateral fits inside the image.

Generate a quadrilateral:

start from square of side approximately N * pixels_per_module_in_image
apply rotation
apply projective corner jitter
apply mild anisotropic scale

Parameters:

rotation: 0..360 degrees
scale: chosen from target px/module
perspective_jitter: e.g. 0..0.25 of side length
aspect_scale: e.g. 0.8..1.2

Reject quadrilaterals that are invalid:

not convex
area too small
corners outside image, unless testing cropping
minimum side length too small
minimum angle too acute

Save corners in order:

TL, TR, BR, BL

relative to QR coordinate system, not necessarily image-space “visual top-left”.

Compute homography:

source patch corners:
  (0, 0)
  (patch_size_px, 0)
  (patch_size_px, patch_size_px)
  (0, patch_size_px)

target image corners:
  TL, TR, BR, BL

Also compute QR-grid homography without quiet-zone if needed:

QR grid coordinates:
  (0, 0)
  (N, 0)
  (N, N)
  (0, N)

image-space QR-code corners:
  project patch coordinates at quiet-zone boundary:
    (quiet_zone * ppm, quiet_zone * ppm)
    ((quiet_zone + N) * ppm, quiet_zone * ppm)
    ((quiet_zone + N) * ppm, (quiet_zone + N) * ppm)
    (quiet_zone * ppm, (quiet_zone + N) * ppm)
5. Warp patch and mask

Create:

patch_rgb
patch_mask

where patch_mask = 1 over the whole rectangular sticker including quiet zone.

Warp both to the background image:

warped_patch = warpPerspective(patch_rgb, H_patch_to_image)
warped_mask  = warpPerspective(patch_mask, H_patch_to_image)

Use interpolation:

patch RGB: linear interpolation
mask: linear interpolation
6. Feather only the outer patch boundary

Feather the rectangular sticker boundary, not the QR modules.

feather_sigma = sampled, e.g. 0.5..2.5 px
alpha = gaussian_blur(warped_mask, feather_sigma)
alpha = clamp(alpha, 0, 1)

Optional contact shadow:

shadow_mask = gaussian_blur(warped_mask, shadow_sigma)
shadow = shadow_strength * shadow_mask
background = background - shadow

Example parameters:

shadow_sigma: 2..8 px
shadow_strength: 0..20 intensity values
shadow_offset: optional, e.g. [1..5 px, 1..5 px]
7. Alpha composite

Use standard alpha compositing:

image = alpha * warped_patch + (1 - alpha) * background

This is the default compositing mode.

Do not use Poisson blending initially. It is a separate optional mode if you later want harder cases.

8. Apply global camera degradation

Apply after compositing, to the whole image.

Recommended augmentations:

Gaussian blur:
  sigma 0..1.5

motion blur:
  optional, length 0..7 px, angle random

sensor noise:
  Gaussian noise sigma 0..8 intensity values

JPEG compression:
  quality 50..100

gamma shift:
  gamma 0.8..1.2

HSV/value shift:
  hue shift small
  saturation scale 0.8..1.2
  value scale 0.8..1.2

For a simple first version, use only:

Gaussian blur
Gaussian noise
JPEG compression
brightness/contrast
9. Save metadata

For every generated image, save:

{
  "sample_index": 123,
  "seed": 123456,
  "background_id": "...",
  "payload": "...",
  "version": 5,
  "N": 37,

  "corners_qr": {

    "TR": [x, y],
    "BR": [x, y],
    "BL": [x, y]
  },
  "homography_grid_to_image": [[...], [...], [...]],
  "homography_patch_to_image": [[...], [...], [...]],
  "augmentations": {
    "rotation_deg": 123.4,
    "perspective_jitter": 0.12,
    "feather_sigma": 1.3,
    "blur_sigma": 0.7,

    "jpeg_quality": 82
  }
}

Minimal first implementation

Start with this exact pipeline:

1. Load deterministic background.
2. Generate QR patch with 4-module quiet zone.
3. Randomize black/white colors slightly.
4. Sample valid quadrilateral.
5. Warp QR patch and rectangular mask.
6. Gaussian-blur mask boundary.
7. Alpha composite onto background.
8. Apply global blur/noise/JPEG.
9. Save image + corners + payload + version.

That is simple, realistic enough, and fully deterministic.
