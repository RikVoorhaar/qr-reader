# Issues

Lightweight issue tracker for the QR Reader project. Each issue lives in its own
file (`NNNN-slug.md`) with YAML frontmatter. Issues double as a to-do list and a
bug log.

## For agents

When working in this repo:

- **Consult this file** before starting new work — check for related open issues.
- **Create an issue** when you find a bug you can't fix inline, or when you
  identify a necessary follow-up task.
- **Speculative enhancements** — ask the maintainer before filing.
- **Closing an issue** — set `status: done` (or `wontfix`) and add `closed:
  YYYY-MM-DD` to the frontmatter, then move it to the Closed table.
